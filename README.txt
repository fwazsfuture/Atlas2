ATLAS — Geography Quest (installable web app prototype)

WHAT'S INCLUDED
- index.html: the app
- manifest.webmanifest: home-screen app metadata
- sw.js: offline cache/service worker
- icon.svg: app icon

HOW TO PUT IT ON YOUR ANDROID HOME SCREEN
1. Upload the contents of this folder to a static HTTPS host (GitHub Pages is a free option).
2. Open the hosted index.html URL in Chrome on your Android phone.
3. Tap Chrome's three-dot menu, then "Install app" or "Add to Home screen".
4. Confirm. Atlas will appear with its own icon and open in app-style full screen.

NOTE
A Progressive Web App needs to be served from HTTPS (or localhost) for installation and offline service-worker features. This ZIP is the source package, not an APK. Progress is saved locally in the browser on this device.
